# 🧠 Low Level Programming - Holberton School

Ce repository regroupe l'ensemble des projets réalisés dans le cadre de la formation **Low Level Programming** à Holberton School.

Ces projets ont pour objectif de maîtriser les **fondamentaux du langage C**, la gestion de la mémoire, les structures de données, ainsi que les concepts bas niveau du système.

---

# 🎯 Objectifs pédagogiques

À travers ces projets, j’ai appris à :

- comprendre le fonctionnement de la mémoire
- manipuler les pointeurs et les tableaux
- utiliser la compilation et le linking
- écrire des programmes performants en C
- implémenter différentes structures de données
- travailler avec les appels système et la gestion de fichiers
