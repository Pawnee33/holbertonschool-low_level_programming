# 🧠 C - More Functions and Nested Loops

Ce projet approfondit les notions vues précédemment sur :

* les fonctions en C
* les boucles imbriquées
* la manipulation des caractères et des nombres

Les exercices consistent à écrire différentes fonctions qui affichent des caractères, effectuent des calculs et manipulent des boucles.

---

# 🎯 Objectifs

À travers ce projet, j’ai appris à :

* créer et utiliser des fonctions
* manipuler les boucles imbriquées
* afficher des caractères avec `_putchar`
* réaliser des calculs simples
* afficher différentes formes géométriques
