# 🧠 C - Hello World

Ce projet introduit les bases du langage **C** et le processus de compilation.

Les exercices permettent de comprendre :

* le préprocesseur
* la compilation
* l’assemblage
* l’édition de liens

---

# 🎯 Objectifs

* comprendre comment compiler un programme C
* écrire un premier programme
* utiliser `printf` et `puts`
* comprendre les étapes de compilation
