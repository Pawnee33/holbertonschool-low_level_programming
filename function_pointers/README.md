# 🧠 C - Function Pointers

Ce projet introduit les **pointeurs de fonctions en C**.

Les pointeurs de fonctions permettent :

* de passer une fonction comme argument
* d'écrire du code générique

---

# 🎯 Objectifs

* comprendre les pointeurs de fonctions
* utiliser des callbacks
