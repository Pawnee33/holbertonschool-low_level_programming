# 🧠 C - malloc & free

Ce projet introduit l'allocation dynamique de mémoire.

Les fonctions utilisées :

* `malloc`
* `free`

---

# 🎯 Objectifs

* comprendre la mémoire dynamique
* créer des tableaux dynamiques
* manipuler la mémoire
