# 🧠 C - argc & argv

Ce projet explique l'utilisation des **arguments de la ligne de commande en C**.

Les programmes peuvent recevoir des arguments via :

* `argc` → nombre d'arguments
* `argv` → tableau contenant les arguments

---

# 🎯 Objectifs

* comprendre `argc` et `argv`
* manipuler les arguments
* écrire des programmes CLI
