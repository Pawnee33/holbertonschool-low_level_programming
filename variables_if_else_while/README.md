# 🧠 C - Variables If Else While

Ce projet introduit les bases de la programmation en **C** :

* variables
* conditions
* boucles

---

# 🎯 Objectifs

* utiliser `if` et `else`
* utiliser les boucles `while`
* manipuler des nombres
