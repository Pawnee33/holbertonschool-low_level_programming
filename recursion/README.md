# 🧠 C - Recursion

Ce projet introduit la **récursivité en langage C**.

La récursivité est une technique où une fonction s'appelle elle-même afin de résoudre un problème.

---

# 🎯 Objectifs

* comprendre le concept de récursion
* écrire des fonctions récursives
* manipuler des chaînes et des nombres avec la récursion
