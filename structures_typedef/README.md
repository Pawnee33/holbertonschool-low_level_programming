# 🧠 C - Structures and Typedef

Ce projet introduit les **structures en C**.

Les structures permettent de regrouper plusieurs variables dans un même type.

---

# 🎯 Objectifs

* comprendre les structures
* utiliser `typedef`
* manipuler des structures
