# 🧠 C - File I/O

Ce projet introduit les **opérations sur les fichiers en C**.

Fonctions système utilisées :

* `open`
* `read`
* `write`
* `close`

---

# 🎯 Objectifs

* lire des fichiers
* écrire dans des fichiers
* manipuler les descripteurs de fichiers
