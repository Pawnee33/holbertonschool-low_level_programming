# 🧠 C - Singly Linked Lists

Ce projet introduit les **listes chaînées simples** en C.

Les listes chaînées sont des structures de données dynamiques composées de nœuds reliés entre eux.

---

# 🎯 Objectifs

* comprendre les listes chaînées
* créer et parcourir une liste
* ajouter et supprimer des éléments
